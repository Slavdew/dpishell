- **Живая проверка 2026-10-17** (сессия с правами, Flowseal удалён владельцем). Проверено и работает:
  - установка и обновление помощника;
  - `alt9` и `alt13` (16/16 целей);
  - быстрый подбор через помощника за 15 с, лучшая `alt13`;
  - режим без службы: окно само поднимает winws, при убитом окне помощник гасит winws;
  - режим службы (автозапуск);
  - «Починить адреса» — проверка и предпросмотр, hosts не тронут;
  - обновление данных с GitHub (уже последняя версия);
  - `--tray`.
- Найдено на живой проверке и исправлено:
  - контрольная группа не шла в подбор → `Shell.WithControl`, в окне не галочка;
  - сбер и т-банк с корнем Минцифры → vk.com, rbc.ru;

- **Окно ↔ роутер по 07** (вкладка «Роутер»):
  - режим «Все сайты / По спискам», «Сайт не открывается», DNS для всей сети, расписание + auto_select;
  - метки TCP (`tcp_timestamps_on`), запрет обхода на ПК и роутере вместе (§6);

  - «Исправить» для flow_offload/ipv6, пакеты-конфликты без кнопки «Остановить», flowoffload «передано обходу».

- **Portable-архив**: `packaging/make-portable.ps1` → `publish/DpiShell-1.0.0-portable.zip`, сторонние лицензии полностью.
