## 2. Откуда брать обновления данных
`raw.githubusercontent.com` у провайдеров блокируют по IP, поэтому нужно зеркало вне GitHub. Варианты: Codeberg, GitLab, Cloudflare Pages.
**По умолчанию:** код обновлений готовлю с несколькими источниками по очереди: GitHub → зеркало. Зеркало подключу, когда выберете и заведёте аккаунт; от вас нужен только аккаунт.
*Код готов (2026-10-17): источники — строки в `data/update-sources.json`, сейчас там только GitHub. Зеркало = одна строка.*

## 3. Роутер роутер: не хватает модуля ядра (от сессии роутера)
В опубликованных пакетах сторонняя прошивка OpenWrt нет `kmod-nft-queue`. Без него обход на роутере не заработает. Автор модуль собирает, но в общий набор он не попал. К тому же набор собран под ядро 6.18.36, а прошивка 1.4.8 — на 6.18.52.
Варианты: попросить автора сторонняя прошивка OpenWrt выложить модуль под 6.18.52 или собрать его самим.
**По умолчанию:** роутер не прошиваем, ждём вашего решения. Подробности — `router/README.md`, установка — `router/INSTALL-роутер.md`.

## 4. Лицензия самого DpiShell
В репозитории нет файла LICENSE — по закону это «все права защищены»: копировать и менять чужим нельзя. Portable-архив собирается без него (сторонние лицензии в нём есть полностью). Обычный выбор для такого проекта — MIT, как у zapret и Flowseal.
**По умолчанию:** LICENSE не добавляю — это решение владельца; скажите «MIT» (или другую), и я положу файл, архив подхватит его сам.
