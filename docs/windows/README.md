# DpiShell для Windows

Обход блокировок YouTube, Discord и других сайтов для всего компьютера — оболочка над zapret (winws от bol-van). Нажали «Включить» — работает; не работает — «Подобрать», программа сама найдёт стратегию и включит её. Без VPN, без телеметрии.

Требования: Windows 10/11 x64. Права администратора нужны один раз — при установке помощника (службы), дальше окно работает без прав.

## Установка

1. Скачайте архив `DpiShell-<версия>-portable.zip` со страницы релизов `windows-vX.Y.Z`: https://github.com/Slavdew/dpishell/releases
2. Распакуйте в любую папку, например `C:\Programs\DpiShell` (не во «Временные файлы» и не в OneDrive). Папку `data` рядом с `DpiShell.exe` не удаляйте и не меняйте.
3. Запустите `DpiShell.exe`. Файл не подписан — SmartScreen может предупредить («Подробнее» → «Выполнить в любом случае»). Установщика нет: удаление — ниже.

## Первые шаги

1. **«Включить».** Первый раз программа попросит права администратора — это установка помощника DpiShell (служба Windows). Ядро обхода (winws, WinDivert из релизов bol-van/zapret) скачается само и проверится по хешам.
2. Если сайты не открылись — **«Подобрать»**: программа перебирает стратегии, проверяет YouTube, Discord и ваши адреса и сама включает лучшую. Во время подбора (1–3 минуты) сайты и игры прерываются.
3. Добавьте **свои адреса** (сайты, которые должны открываться), отметьте «важный» у тех, без которых подбор считать неудачным.

## Что умеет

- **Главная**: состояние (Выключено / Работает / Подбор / Ошибка), выбор стратегии отдельно от выключателя (порядок — по статистике прошлых подборов), «Включить/Выключить», «Подобрать», «Проверить сейчас».
- **Подбор**: быстрый (первая стратегия, у которой всё открылось), полный (все, с таблицей), глубокий (придумывает новые стратегии, когда готовые не помогли — до получаса). Законченный подбор сам включает лучшую. Критерий «сайт работает» строгий: TLS 1.2 и 1.3, страница скачана целиком, без редиректа на чужой хост; «обычные сайты» не должны ломаться.
- **Режим службы** (по умолчанию): обход работает как служба Windows — после перезагрузки и без открытого окна. Без службы — обход живёт, пока открыта программа (тогда она по умолчанию запускается вместе с Windows в трее).
- **Списки доменов и исключения**: обход применяется к сайтам из списков; свои сайты — на вкладке «Сайты»; у роутера там же исключения («На роутере») и проверка «Сайт не открывается».
- **IP-списки** и **игровой режим** — для игр и программ, которые не сообщают имя сайта; выключены по умолчанию, у каждого «(i)» с объяснением.
- **«Починить адреса»** — для случаев, когда провайдер блокирует адрес сервера (загрузки GitHub, Telegram Web, запуск Discord): записывает проверенные адреса в hosts своим блоком, с копией и «Вернуть как было».
- **DNS** (отдельная вкладка) — если провайдер подменяет ответы DNS: один клик включает защищённый DNS (Google, Cloudflare, Quad9 или свой) только на физических адаптерах, с проверкой после переключения и «Вернуть как было».
- **Диагностика** (этот компьютер): что мешает обходу (другие программы обхода, VPN, прокси, «игровые» сетевые службы, hosts) — у каждой находки написано, что сделать; «Очистить кэш Discord»; «Сохранить отчёт» (без паролей и личных данных).
- **Обновления**: списки и данные проверяются раз в день, ставятся по кнопке на вкладке «Информация и обновления» (блок «Версия»: версии программы, помощника, данных, ядра и DpiShell на роутере); новая версия программы — ссылкой на релиз.
- **Роутер**: если в домашней сети роутер с OpenWrt и [DpiShell для роутера](../router/README.md), приложение его находит и управляет им: подбор на роутере, отправка найденной стратегии, DNS для всей сети, «Роутер: что мешает». Обход на ПК и на роутере одновременно не работают — программа следит за этим сама.
- Трей, автозапуск, тёмная/светлая тема, одна копия окна.

Подробнее о каждой функции — кнопки «(i)» в окне (тексты — [../info-texts.md](../info-texts.md)); как всё устроено — [../dev/architecture.md](../dev/architecture.md).

## Как выглядит

Снимки экрана появятся в следующих версиях.

## Удаление полностью

1. Если включали «Починить адреса» — там «Вернуть как было». Если меняли DNS — «Вернуть как было» на вкладке «DNS».
2. «Диагностика» → снять галочку «Запускать вместе с Windows».
3. Там же: «Удалить службу полностью» (служба обхода и драйвер WinDivert; возвращает временные метки TCP, если их включала программа).
4. Там же: «Удалить помощника» (один запрос прав администратора).
5. Закройте программу: значок в трее → «Выход».
6. Удалите папку с программой и папки `%LocalAppData%\DpiShell` (настройки окна) и `%ProgramData%\DpiShell` (данные и ядро; нужны права администратора).

## Частые проблемы

| Что видно | Почему | Что делать |
|---|---|---|
| «Файлы ядра изменены или удалены (антивирус?)» | антивирус удалил WinDivert — известное ложное срабатывание на перехватчик пакетов | «Восстановить»; добавить папку `%ProgramData%\DpiShell` в исключения антивируса |
| «Работает другой обход» | Flowseal, другой zapret, GoodbyeDPI | «Остановить» в окне или выключить их самостоятельно — два обхода вместе ломают сайты |
| Включено, а сайты не открываются | стратегия перестала подходить (провайдер поменял оборудование, другая сеть) | «Проверить сейчас» → «Подобрать»; посмотреть «Диагностику» |
| «DNS провайдера подменяет адреса» | провайдер отвечает «имени нет» на заблокированные сайты; браузеры это обходят сами, Discord и игры — нет | кнопка на плашке включает защищённый DNS; подробнее — [../research/dns.md](../research/dns.md) |
| «Блокировок не обнаружено или включён VPN» | всё открывается и без обхода | обход не нужен; при VPN — выключите VPN на время подбора |
| «Обход делает роутер» | в сети найден роутер с DpiShell и включённым обходом | управляйте с вкладки «Роутер»; обход на ПК включится только после выключения на роутере |
| Discord не подключается после смены стратегии | кэш неудачных ответов | «Диагностика» → «Очистить кэш Discord» |
| Драйвер не запускается (Secure Boot) | подпись драйвера WinDivert | текст из документации zapret: отключить Secure Boot или включить testsigning |
| Игра/VPN/удалённый рабочий стол стали сбоить | включён игровой режим или «Все адреса» | выключить их |

## Планируется

- Обновление самой программы по кнопке с проверкой подписи и возможностью откатиться; подписанные выпуски и манифест данных.
- Установка DpiShell на роутер с OpenWrt из окна (по SSH), удаление с роутера из окна.
