# DpiShell для роутера с OpenWrt

Оптимизация соединения для всех устройств дома (телефоны, ТВ, приставки, компьютеры) — пакеты для OpenWrt `dpishell` (оптимизация, подбор стратегий, API) и `luci-app-dpishell` (страница DpiShell в меню роутера — обычно «Службы → DpiShell», название может отличаться; короткий адрес `http://192.168.1.1/dpi`). Ядро — zapret (nfqws от bol-van): роутер скачивает его сам под свою архитектуру и сверяет по хешу. Управлять можно с телефона в браузере или из [приложения на ПК](../windows/README.md). Страница показывается на языке LuCI (русский или английский; язык задаётся в настройках LuCI).

**Установка самой OpenWrt — под ответственность пользователя**, см. документацию OpenWrt и вашей прошивки. Пакет прошивку не ставит и не меняет.

## Что нужно

- OpenWrt 25.x (или snapshot) с пакетным менеджером `apk` и межсетевым экраном fw4 (nftables). Сборка под `opkg` (OpenWrt 24.10) планируется.
- В фиде прошивки — `kmod-nft-queue` под ядро роутера (проверка ниже). Без него оптимизация не работает. В неофициальных прошивках модули ядра в фиде могут не совпадать с ядром образа.
- Свободное место: ~2 МБ на флеше под ядро zapret (архив ~8 МБ качается во временную память). Ресурсов обычно хватает на большинстве роутеров: nfqws видит только первые пакеты каждого соединения; на слабых устройствах с малым объёмом памяти работу не гарантируем.
- Чужой zapret (пакеты `zapret`, `luci-app-zapret`, менеджеры zapret) — удалить: он занимает те же папки.

Адрес роутера в примерах — `192.168.1.1` (умолчание OpenWrt); у вас может быть другой.

## Проще всего — из приложения на ПК

В [приложении DpiShell для Windows](../windows/README.md), вкладка «Роутер», — «Установить на роутер». Нужен адрес роутера и пароль администратора — обычно тот же, что для входа в его настройки (LuCI). Программа сама проверит, подходит ли роутер (OpenWrt, `apk`, `kmod-nft-queue` под ядро, место, похожая программа), поставит пакеты и ядро. Если у роутера нет доступа к GitHub, программа пустит его через компьютер. Там же — «Обновить роутер» и «Удалить DpiShell с роутера…».

Ниже — то же вручную, для тех, кто привык к командной строке.

## Проверка перед установкой

```
ssh root@192.168.1.1
apk update
uname -r
apk search -v kmod-nft-queue
```
Версия `kmod-nft-queue` должна начинаться с того же, что `uname -r`. Иначе — стоп: модуль не загрузится.

## Установка из фида

```
wget -O /etc/apk/keys/dpishell.pem https://slavdew.github.io/dpishell/feed/dpishell.pem
sha256sum /etc/apk/keys/dpishell.pem
```
Сверить: `e3d98812b312b8c1475f7c98c72cb850ea87c90fdcd81bcd803dad7f9f9a1543`. Не совпало — `rm /etc/apk/keys/dpishell.pem` и не продолжать.

```
echo https://slavdew.github.io/dpishell/feed/packages.adb >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add dpishell luci-app-dpishell
```

Релизы роутерной части — лента `router-vX.Y.Z` на https://github.com/Slavdew/dpishell/releases: пакеты, `release.json` (что нового и sha256 файлов) и его подпись.

## Первые шаги

Откройте `http://192.168.1.1/dpi` (или страницу DpiShell в меню роутера — обычно «Службы → DpiShell», название может отличаться; вход — пароль роутера):
1. «Загрузить ядро» — роутер скачает архив zapret с GitHub (или зеркала), проверит хеши и поставит ядро.
2. Предупреждение про ускорение сети (flow offloading) — «Исправить»: системная разгрузка несовместима с оптимизацией, zapret ведёт её сам; скорость обычно почти не меняется, на быстрых тарифах с аппаратным ускорением может снизиться.
3. «Подобрать» → полный. Обычно несколько минут; сайты в сети в это время могут моргать. Законченный подбор сам включает лучшую стратегию.
4. Если появилось «Компьютерам на Windows нужна настройка» — на компьютерах с приложением DpiShell оно включит её само; на остальных Windows — один раз от администратора `netsh int tcp set global timestamps=enabled`. На большинстве телефонов, Mac и Linux ничего не нужно.

## Что умеет страница

- **Оптимизация**: состояние, Включить/Выключить, Проверить, Подобрать. «Включить» без стратегии — подбирает и включает сам. Стратегия и режим меняются кнопкой «Применить» — оптимизация для всей сети перезапустится, сайты моргнут на пару секунд.
- **Для каких сайтов**: «Все сайты» (по умолчанию — оптимизация для всего, кроме исключений) или «Только из списков». «Сайт не открывается» — роутер проверит адрес с оптимизацией и без и предложит добавить в исключения.
- **Подбор**: быстрый/полный; страницу можно закрыть — подбор идёт на роутере. Если готовые стратегии не помогли, после результата появляется «Искать глубже (до 15 мин)»: роутер создаёт и проверяет новые стратегии, сайты и игры в это время прерываются; не нашлось — всё возвращается как было. Отдельную стратегию можно проверить кнопкой «Проверить только её», не запуская весь подбор.
- **Проверять сам** (по умолчанию раз в час): две неудачи подряд — переключение на запасную стратегию; «Если не помогло — подобрать заново» (выключено по умолчанию — подбор даёт перебои на всех устройствах).
- **Исключения и списки**: исключения (свои и по умолчанию), свои сайты для оптимизации (в режиме «Только из списков»), свои сайты для проверки.
- **DNS для всей сети**: анализ подмены DNS провайдером; «Включить защищённый DNS» (Google + Cloudflare, Google, Cloudflare, Quad9, Яндекс, свой) через штатный `https-dns-proxy`; «Вернуть как было». Последствия показываются до включения.
- **Диагностика**: «Что мешает» — список проверок, у каждой отметка, вывод и кнопка действия, сверху общая оценка; похожие программы («Остановить»), ускорение сети и IPv6 («Исправить»; без оптимизации по IPv6 YouTube пойдёт мимо, если провайдер даёт IPv6), DNS, ядро («Восстановить»), «Сохранить отчёт» (ваши адреса в нём скрыты), «Удаление DpiShell».
- **Свои настройки** («Диагностика», карточка «Свои настройки»): «Выгрузить…» и «Загрузить настройки» — папка или архив .zip с текстовыми файлами: свои сайты, исключения, стратегии, DNS. Перед записью показывается, что добавится, что заменится и что пропущено; текущие настройки сохраняются копией. Формат общий с приложением на ПК: [../settings-export.md](../settings-export.md). Строки hosts и профили игр относятся к ПК и при загрузке на роутере пропускаются с причиной.
- **Обновление**: раз в сутки роутер проверяет, нет ли новой версии; если есть — на главной плашка «Доступно обновление» с тем, что нового, и кнопка «Обновить». Страница перезагрузится сама.

## Если GitHub с роутера недоступен

Пакеты DpiShell лежат на GitHub Pages, ядро zapret — на github.com. Если провайдер ограничивает доступ к ним, проще всего поставить из приложения на ПК (см. выше): оно пустит роутер в интернет через компьютер. Вручную — офлайн-набор, который собирают на компьютере под фиды и ключи именно этого роутера (для разработчиков: нужен эмулятор OpenWrt):

1. На роутере выгрузить фиды и ключи: `tar -czf /tmp/feeds.tgz /etc/apk/repositories.d /etc/apk/keys /etc/openwrt_release`, забрать: `scp -O root@192.168.1.1:/tmp/feeds.tgz .`
2. На компьютере, в папке репозитория: `sh router/tools/offline-bundle.sh router/offline-bundle feeds.tgz` (нужен эмулятор OpenWrt — [../dev/building.md](../dev/building.md)). Получится папка с DpiShell, недостающими пакетами прошивки (в том числе `kmod-nft-queue`), архивом ядра и `install.sh`; подписи пакетов проверяются при сборке ключами роутера.
3. `scp -O -r router/offline-bundle root@192.168.1.1:/tmp/dpishell-offline` и `ssh root@192.168.1.1 "sh /tmp/dpishell-offline/install.sh"` — сверит суммы, архитектуру и ядро, поставит только недостающее, ядро — из набора, без сети.

Если недоступен только github.com (ядро), архив ядра загрузит приложение на ПК — проверка хешей та же.

## Удаление

Из приложения на ПК — «Удалить DpiShell с роутера…». На странице роутера — «Диагностика» → внизу «Удаление DpiShell»: выбрать «Сохранить настройки» (свои сайты, исключения, найденные стратегии вернутся при повторной установке) или «Удалить полностью», ввести слово «удалить». Оптимизация выключится, значения, которые были до DpiShell (ускорение сети, DNS, расписание), вернутся на место; если вы меняли их позже сами, эти правки могут быть перезаписаны; пакеты и ядро zapret удалятся; модули ядра и другие пакеты останутся.

Без страницы: `apk del luci-app-dpishell dpishell` делает ту же очистку с сохранением настроек.

## Если всё сломалось
Сайты перестали открываться, а страница роутера не открывается — оптимизацию можно выключить кнопкой на самом роутере.

На большинстве роутеров с OpenWrt нажатие reset (скрепкой) на 2 секунды выключает оптимизацию без перезагрузки, но на вашем может работать иначе. Не держите reset 5 секунд и дольше — обычно это сброс к заводским настройкам. Кнопка WPS, если она есть, обычно тоже выключает оптимизацию одним нажатием.
Если роутер всё же перезагрузился, он поднимется уже без оптимизации.

Включить оптимизацию снова можно со страницы роутера или из приложения на ПК.

Роутер страхует и сам. Раз в 5 минут он проверяет обычные сайты (ВКонтакте, РБК, Госуслуги). Если с оптимизацией они не открываются, а без неё открываются, оптимизация выключается, а на странице появляется причина. Затем роутер один раз сам подбирает стратегию: нашёл — включает её, не нашёл — оптимизация остаётся выключенной, и снова сам он не пробует, пока вы не включите оптимизацию или не запустите подбор. Если интернета нет и без оптимизации, скорее всего это обрыв у провайдера: оптимизация остаётся включённой. После «Включить» из приложения на ПК роутер ждёт 3 минуты, что всё работает, иначе возвращает как было.

## Частые проблемы

| Что видно | Почему | Что делать |
|---|---|---|
| «Нет kmod-nft-queue» / модуль не загружается | в фиде прошивки модуль под другое ядро | проверка выше; обновить прошивку до версии, под которую есть фид, или офлайн-набор |
| «Файлы ядра повреждены» | хеш nfqws не совпал | «Восстановить» в «Диагностике» |
| «Работает похожая программа» | zapret2, youtubeUnblock, b4 или чужой zapret пакетом | «Остановить»; пакеты — удалить (`apk del zapret luci-app-zapret …`) |
| «Включено ускорение сети» | системная разгрузка fw4 несовместима с nfqws | «Исправить» |
| Сайты открываются на телефоне, но не на Windows | стратегия требует временных меток TCP | п. 4 первых шагов |
| После смены режима часть сайтов сломалась | стратегия подобрана под другой режим | роутер сам запускает полную проверку; «Подобрать» заново или «Сайт не открывается» → в исключения |
| После «Вернуть как было» в DNS имена не разрешаются | dnsmasq не перезапустился | роутер перезапускает его сам; если нет — `/etc/init.d/dnsmasq restart` |
| После обновления прошивки оптимизация пропала | sysupgrade обычно сохраняет настройки в `/etc`, если вы не отказались от этого, но пакеты и ядро нужно ставить заново | сделайте резервную копию перед обновлением; после него поставьте пакеты заново |
