# DpiShell для роутера с OpenWrt

Обход блокировок для всех устройств дома (телефоны, ТВ, приставки, компьютеры) — пакеты для OpenWrt `dpishell` (обход, подбор стратегий, API) и `luci-app-dpishell` (страница «Службы → DpiShell», короткий адрес `http://192.168.1.1/dpi`). Ядро — zapret (nfqws от bol-van): роутер скачивает его сам под свою архитектуру и сверяет по хешу. Управлять можно с телефона в браузере или из [приложения на ПК](../windows/README.md).

**Установка самой OpenWrt — под ответственность пользователя**, см. документацию OpenWrt и вашей прошивки. Пакет прошивку не ставит и не меняет.

## Что нужно

- OpenWrt 25.x (или snapshot) с пакетным менеджером `apk` и межсетевым экраном fw4 (nftables). Сборка под `opkg` (OpenWrt 24.10) планируется.
- В фиде прошивки — `kmod-nft-queue` под ядро роутера (проверка ниже). Без него обход не работает. В неофициальных прошивках модули ядра в фиде могут не совпадать с ядром образа.
- Свободное место: ~2 МБ на флеше под ядро zapret (архив ~8 МБ качается во временную память). Ресурсы — любые современные: nfqws видит только первые пакеты каждого соединения.
- Чужой zapret (пакеты `zapret`, `luci-app-zapret`, менеджеры zapret) — удалить: он занимает те же папки.

Адрес роутера в примерах — `192.168.1.1` (умолчание OpenWrt); у вас может быть другой.

## Проверка перед установкой

```
ssh root@192.168.1.1
apk update
uname -r
apk search -v kmod-nft-queue
```
Версия `kmod-nft-queue` должна начинаться с того же, что `uname -r`. Иначе — стоп: модуль не загрузится.

## Установка из фида

```
wget -O /etc/apk/keys/dpishell.pem https://slavdew.github.io/dpishell/feed/dpishell.pem
sha256sum /etc/apk/keys/dpishell.pem
```
Сверить: `e3d98812b312b8c1475f7c98c72cb850ea87c90fdcd81bcd803dad7f9f9a1543`. Не совпало — `rm /etc/apk/keys/dpishell.pem` и не продолжать.

```
echo https://slavdew.github.io/dpishell/feed/packages.adb >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add dpishell luci-app-dpishell
```

Релизы роутерной части — лента `router-vX.Y.Z` на https://github.com/Slavdew/dpishell/releases (там же офлайн-набор).

## Первые шаги

Откройте `http://192.168.1.1/dpi` (или «Службы → DpiShell», вход — пароль роутера):
1. «Загрузить ядро» — роутер скачает архив zapret с GitHub (или зеркала), проверит хеши и поставит ядро.
2. Предупреждение про ускорение сети (flow offloading) — «Исправить»: системная разгрузка несовместима с обходом, zapret ведёт её сам без потери скорости.
3. «Подобрать» → полный. 2–3 минуты; сайты в сети в это время могут моргать. Законченный подбор сам включает лучшую стратегию.
4. Если появилось «Компьютерам на Windows нужна настройка» — на компьютерах с приложением DpiShell оно включит её само; на остальных Windows — один раз от администратора `netsh int tcp set global timestamps=enabled`. Телефонам, Mac и Linux ничего не нужно.

## Что умеет страница

- **Обход**: состояние, Включить/Выключить, Проверить, Подобрать. «Включить» без стратегии — подбирает и включает сам. Стратегия и режим меняются кнопкой «Применить» — обход для всей сети перезапустится, сайты моргнут на пару секунд.
- **Для каких сайтов**: «Все сайты» (по умолчанию — обход для всего, кроме исключений) или «Только из списков». «Сайт не открывается» — роутер проверит адрес с обходом и без и предложит добавить в исключения.
- **Подбор**: быстрый/полный, «Глубокий поиск» (новые стратегии, около 10 минут); страницу можно закрыть — подбор идёт на роутере.
- **Проверять сам** (по умолчанию раз в час): две неудачи подряд — переключение на запасную стратегию; «Если не помогло — подобрать заново» (выключено по умолчанию — подбор даёт перебои на всех устройствах).
- **Исключения и списки**: исключения (свои и по умолчанию), свои сайты для обхода (в режиме «Только из списков»), свои адреса для проверки.
- **DNS для всей сети**: анализ подмены DNS провайдером; «Включить защищённый DNS» (Google + Cloudflare, Google, Cloudflare, Quad9, Яндекс, свой) через штатный `https-dns-proxy`; «Вернуть как было». Последствия показываются до включения.
- **Диагностика**: чужие обходы («Остановить»), ускорение сети и IPv6 («Исправить»; без обхода по IPv6 YouTube пойдёт мимо, если провайдер даёт IPv6), DNS, ядро («Восстановить»), «Сохранить отчёт» (ваши адреса в нём скрыты), «Удаление DpiShell».
- **Обновление**: раз в сутки роутер проверяет, нет ли новой версии; если есть — на главной плашка «Доступно обновление» с тем, что нового, и кнопка «Обновить». Страница перезагрузится сама.

## Если GitHub с роутера недоступен

Пакеты DpiShell лежат на GitHub Pages, ядро zapret — на github.com. Если провайдер их режет, набор собирают на компьютере, где интернет работает, — под фиды и ключи именно этого роутера:

1. На роутере выгрузить фиды и ключи: `tar -czf /tmp/feeds.tgz /etc/apk/repositories.d /etc/apk/keys /etc/openwrt_release`, забрать: `scp -O root@192.168.1.1:/tmp/feeds.tgz .`
2. На компьютере, в папке репозитория: `sh router/tools/offline-bundle.sh router/offline-bundle feeds.tgz` (нужен эмулятор OpenWrt — [../dev/building.md](../dev/building.md)). Получится папка с DpiShell, недостающими пакетами прошивки (в том числе `kmod-nft-queue`), архивом ядра и `install.sh`; подписи пакетов проверяются при сборке ключами роутера.
3. `scp -O -r router/offline-bundle root@192.168.1.1:/tmp/dpishell-offline` и `ssh root@192.168.1.1 "sh /tmp/dpishell-offline/install.sh"` — сверит суммы, архитектуру и ядро, поставит только недостающее, ядро — из набора, без сети.

Если недоступен только github.com (ядро), архив ядра можно загрузить со страницы или из приложения на ПК (у него есть копия того же архива) — проверка хешей та же.

## Удаление

«Диагностика» → внизу «Удаление DpiShell»: выбрать «Сохранить настройки» (свои адреса, исключения, найденные стратегии вернутся при повторной установке) или «Удалить полностью», ввести слово «удалить». Обход выключится, всё, что DpiShell менял в настройках роутера (ускорение сети, DNS, расписание), вернётся как было, пакеты и ядро обхода удалятся; модули ядра и другие пакеты останутся.

Без страницы: `apk del luci-app-dpishell dpishell` делает ту же очистку с сохранением настроек.

## Частые проблемы

| Что видно | Почему | Что делать |
|---|---|---|
| «Нет kmod-nft-queue» / модуль не загружается | в фиде прошивки модуль под другое ядро | проверка выше; обновить прошивку до версии, под которую есть фид, или офлайн-набор |
| «Файлы обхода повреждены» | хеш nfqws не совпал | «Восстановить» в «Диагностике» |
| «Работает другой обход» | zapret2, youtubeUnblock, b4 или чужой zapret пакетом | «Остановить»; пакеты — удалить (`apk del zapret luci-app-zapret …`) |
| «Включено ускорение сети» | системная разгрузка fw4 несовместима с nfqws | «Исправить» |
| Сайты открываются на телефоне, но не на Windows | стратегия требует временных меток TCP | п. 4 первых шагов |
| После смены режима часть сайтов сломалась | стратегия подобрана под другой режим | роутер сам запускает полную проверку; «Подобрать» заново или «Сайт не открывается» → в исключения |
| После «Вернуть как было» в DNS имена не разрешаются | dnsmasq не перезапустился | роутер перезапускает его сам; если нет — `/etc/init.d/dnsmasq restart` |
| После обновления прошивки обход пропал | sysupgrade затирает пакеты | настройки и свои данные сохраняются; поставить пакеты заново |

## Планируется

- Установка, обновление и удаление DpiShell на роутере из приложения на ПК (по SSH, в том числе когда у роутера нет доступа к GitHub — через компьютер).
- Пакеты для OpenWrt 24.10 (opkg).
